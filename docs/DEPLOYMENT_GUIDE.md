
## 六、部署流程清单

### 1. 环境准备

```bash
# 1. 安装Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. 安装PM2
npm install -g pm2

# 3. 安装Nginx
sudo apt-get install -y nginx

# 4. 安装Docker
curl -fsSL https://get.docker.com | sh
```

### 2. 后端部署

```bash
# 1. 克隆代码
git clone https://github.com/your-repo/sweet-match-backend.git

# 2. 安装依赖
cd sweet-match-backend
npm install

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 配置数据库、Redis等

# 4. 构建项目
npm run build

# 5. 启动服务
pm2 start dist/main.js --name sweet-match-api

# 6. 配置Nginx反向代理
sudo nano /etc/nginx/sites-available/sweet-match
```

### 3. 管理后台部署

```bash
# 1. 克隆代码
git clone https://github.com/your-repo/sweet-match-admin.git

# 2. 安装依赖
cd sweet-match-admin
npm install

# 3. 构建项目
npm run build

# 4. 上传到OSS/COS
# 或使用Nginx静态托管
```

### 4. 数据库初始化

```bash
# 1. 创建数据库
mysql -u root -p
CREATE DATABASE sweet_match;

# 2. 导入表结构
mysql -u root -p sweet_match < docs/database/schema.sql

# 3. 初始化数据
mysql -u root -p sweet_match < docs/database/init_data.sql
```
